# להוציא את המערכת החוצה

עמוד שיתוף הוא כתובת שהלקוחה פותחת בטלפון שלה. כל עוד המערכת רצה רק על
המחשב שלך, `localhost` לא קיים אצל אף אחד אחר. המסמך הזה מסביר איך לתת
למערכת כתובת אמיתית — ומה חייב להיות מוגדר לפני שעושים את זה.

---

## חלק א׳ — לפני שנפתחים החוצה (חובה)

### 1. סוד חתימה

```bash
pnpm setup:secret
```

יוצר `APP_SECRET` אקראי ושומר ב-`.env.local`.

**למה זה חובה:** הסוד חותם את עוגיית הסשן. בלעדיו המערכת נופלת לסוד שכתוב
בקוד — וכל מי שראה את הקוד יכול לחתום עוגייה ולהיכנס בלי סיסמה. לכן הרצת
`pnpm start` בלי `APP_SECRET` **מסרבת לעלות** ומחזירה שגיאה.

הקובץ `.env.local` לא נכנס לגיט. שינוי הסוד מנתק אותך ותצטרך להיכנס מחדש.

### 2. סיסמה אמיתית

```bash
node scripts/seed.mjs your@email סיסמה-ארוכה-וקשה
```

ברגע שהמערכת ברשת, `samuel` היא לא סיסמה.

**מה כבר מוגן:** אחרי 10 ניסיונות כניסה כושלים מאותה כתובת, הכניסה נחסמת
לרבע שעה — כולל לסיסמה הנכונה.

### 3. גיבוי לפני

```bash
cp jewelry.db "backups/jewelry-$(date +%Y%m%d).db"
```

## חלק ב׳ — המנהרה

מנהרה נותנת למערכת שרצה אצלך כתובת `https` ציבורית. המידע נשאר על המחשב
שלך; רק התעבורה עוברת דרך Cloudflare.

### התקנה

```
Windows:  winget install --id Cloudflare.cloudflared
macOS:    brew install cloudflared
```

### הרצה

שני חלונות טרמינל:

```bash
# חלון 1 — המערכת
pnpm build && pnpm start

# חלון 2 — המנהרה
pnpm tunnel
```

הסקריפט מדפיס את הכתובת ו**שומר אותה אוטומטית בהגדרות**, כך שכל לינקי
השיתוף ייבנו ממנה מאותו רגע.

---

## חלק ג׳ — כתובת זמנית מול כתובת קבועה

| | כתובת זמנית (`pnpm tunnel`) | כתובת קבועה |
|---|---|---|
| עלות | חינם | חינם, אבל צריך דומיין |
| הכתובת | `xxx.trycloudflare.com`, **משתנה בכל הפעלה** | `shop.הדומיין-שלך.com`, קבועה |
| מתאים ל | לבדוק, ולשלוח לינק שנפתח היום | לינק באינסטגרם, קטלוג, לינק שנשלח וממתין |

### הבעיה עם כתובת זמנית

כשסוגרים את החלון הכתובת מתה. בהפעלה הבאה מתקבלת כתובת אחרת — **וכל לינק
שכבר שלחת מפסיק לעבוד.** ללקוחה שפותחת את הלינק יומיים אחרי שקיבלה אותו,
הוא שבור.

הסלאג עצמו (`/p/sam-0001-68e8c72a`) לא משתנה לעולם. רק החלק של הדומיין
מתחלף. לכן כתובת קבועה פותרת את זה סופית.

### כתובת קבועה — פקודה אחת

```bash
pnpm setup:tunnel shop.הדומיין-שלך.com
```

הסקריפט עושה הכל: מתחבר ל-Cloudflare (נפתח דפדפן פעם אחת), יוצר מנהרה,
מפנה את הכתובת אליה, כותב את קובץ ההגדרות, ושומר את הכתובת ב-`.env.local`.
כדי לראות מה הוא עומד לעשות בלי לבצע:

```bash
pnpm setup:tunnel shop.הדומיין-שלך.com --dry-run
```

מכאן והלאה, בכל הפעלה — שני חלונות:

```bash
pnpm build && pnpm start
cloudflared tunnel run samuel
```

**הכתובת לא תשתנה יותר. לינק שתשלח היום יעבוד גם בעוד שנה.**

## על הדומיין

### לא צריך דומיין חדש

אם כבר יש לך דומיין לעסק, **תת-דומיין מספיק** — `shop.` או `catalog.`
לפני הדומיין הקיים. לא עולה כלום ולא נוגע באתר הקיים.

### התנאי היחיד: ה-DNS מנוהל ב-Cloudflare

זה הדבר היחיד שיכול לעכב. Cloudflare צריכה לנהל את רשומות ה-DNS של הדומיין
כדי שתוכל להפנות כתובת אל המנהרה.

| המצב שלך | מה עושים |
|---|---|
| הדומיין כבר ב-Cloudflare | כלום. מריצים את הפקודה. |
| דומיין אצל רשם אחר | מוסיפים אותו לחשבון Cloudflare (חינם) ומחליפים nameservers אצל הרשם. לוקח כמה שעות עד שזה נתפס. |
| אין דומיין | קונים. `.com` דרך Cloudflare Registrar בערך $10 לשנה, וה-DNS מוגדר מיד. |

**`.co.il`:** Cloudflare לא מוכרת אותם, אבל אפשר לקנות אצל רשם ישראלי
ולהעביר רק את ה-DNS ל-Cloudflare. עובד בדיוק אותו דבר.

### איך לדעת אם יש לך דומיין

- קיבלת פעם מייל על חידוש דומיין?
- יש לעסק אתר או מייל בכתובת שאינה gmail?
- חפש במייל: "domain renewal", "חידוש דומיין", "nameservers".

אם התשובה לא — פשוט תקנה אחד. זו ההוצאה הקטנה ביותר בפרויקט הזה.

## מה חשוף ומה לא

| כתובת | מי נכנס |
|---|---|
| `/p/[slug]` · `/c/[slug]` | כל אחד עם הלינק — רק לדגמים ולקולקציות **שפורסמו** |
| `/factory/[token]` | המפעל שקיבל את הלינק. מפרט טכני בלבד — בלי לקוח, מחיר או רווח |
| `/photos/[id]` | תמונה של דגם מפורסם. אחרת — רק עם סשן |
| כל השאר | רק אחרי כניסה בסיסמה |

לקוחות, הזמנות, תמחור ורווחיות **אינם נגישים** מבחוץ בשום מצב.

ביטול פרסום של דגם מחזיר 404 מיידית, והתמונות שלו נסגרות איתו.
