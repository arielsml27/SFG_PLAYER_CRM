# SFG Player CRM

מערכת CRM פנימית לסוכנות שחקנים — רצה **מקומית לגמרי** על המחשב שלך, בלי תלות בענן.

## טכנולוגיה

- **Next.js 16** + TypeScript + App Router
- **Tailwind CSS 4** — עיצוב שחור/לבן/אפור עם נגיעות זהב, תמיכה מלאה ב-RTL
- **SQLite** דרך **Drizzle ORM**, עם קובץ `dev.db` יחיד בתיקיית הפרויקט
  > הפרויקט המקורי תוכנן עם Prisma, אך הוחלף ל-Drizzle + מודול ה-SQLite המובנה
  > של Node.js (`node:sqlite`) כדי שהמערכת תעבוד **בלי שום הורדת בינארי חיצוני**
  > (חשוב עבור מחשב שעלול לא להיות תמיד מחובר לאינטרנט, ועבור אבטחה — פחות תלות
  > בספריות native חיצוניות שמטפלות במידע רגיש על קטינים ומשפחות).

## התקנה והרצה ראשונה

```bash
pnpm install
pnpm db:migrate     # יוצר את dev.db ואת כל הטבלאות
pnpm db:seed        # (אופציונלי) מכניס 24 שחקני דוגמה + מועדונים כדי לנסות את המערכת מיד
pnpm dev
```

פתח בדפדפן:

```
http://localhost:3000
```

### אם pnpm install מציג "ignored build scripts"

זו הודעה תקנית של pnpm (לא שגיאה). הרץ פעם אחת:

```bash
pnpm approve-builds
```

ובחר `esbuild` (משמש רק לכלי הפיתוח `drizzle-kit`, לא לאפליקציה עצמה).

## מבנה הפרויקט

```
src/
  app/                # דפי Next.js (App Router)
    page.tsx           → דשבורד ראשי
    players/            → רשימת שחקנים, יצירה, עריכה, פרופיל מלא (10 טאבים)
    tasks/              → כל המשימות של הסוכנות
    clubs/               → ניהול מועדונים
    api/export/players/ → ייצוא CSV
  components/          # רכיבי UI משותפים (טופס שחקן, badge, טבלאות...)
  db/
    schema.ts           → כל טבלאות ה-SQLite (Player, Club, ClubContract,
                           RepresentationAgreement, PlayerLink, Video, Document,
                           Contact, TimelineEvent, Task, Deal)
    index.ts             → חיבור ל-SQLite (node:sqlite) + Drizzle
  lib/
    data.ts              → כל שאילתות הקריאה (דשבורד, רשימות, פרופיל שחקן)
    actions.ts           → כל הפעולות (Server Actions): יצירה/עריכה/מחיקה
    constants.ts          → כל הסטטוסים/enum-ים בעברית
    format.ts             → פורמט תאריכים, גיל, כסף
drizzle/                # קבצי מיגרציה SQL שנוצרו מה-schema
scripts/
  migrate.mjs            → מריץ מיגרציות על dev.db
  seed.mjs                → מכניס נתוני דוגמה
```

## פקודות שימושיות

| פקודה | מה זה עושה |
|---|---|
| `pnpm dev` | הרצת שרת פיתוח על `localhost:3000` |
| `pnpm build && pnpm start` | הרצה במצב production מקומי |
| `pnpm db:generate` | יוצר קובץ מיגרציה SQL חדש אחרי שינוי ב-`src/db/schema.ts` |
| `pnpm db:migrate` | מחיל את כל המיגרציות שעדיין לא רצו על `dev.db` |
| `pnpm db:seed` | מכניס נתוני דוגמה (24 שחקנים, 10 מועדונים, משימות...) |

## מה כבר בנוי (Phase 1 מלא לפי המפרט)

- ✅ יצירה / עריכה / מחיקה (עם אישור כפול) של שחקן
- ✅ רשימת שחקנים עם חיפוש וסינון לפי סטטוס ועמדה
- ✅ עמוד פרופיל שחקן מלא עם **11 טאבים**: פרטים כלליים, חוזה מועדון, ייצוג,
  מקצועי, לינקים, סרטונים, מסמכים, אנשי קשר, יומן אירועים, משימות, עסקאות
- ✅ דשבורד עם: שחקנים פעילים, חוזים/ייצוג שמסתיימים ב-90 יום הקרובים,
  משימות קריטיות, שחקנים עם מידע חסר (חוזה / ייצוג / לינק סטטיסטיקה / וידאו / איש קשר)
- ✅ ייצוא CSV של רשימת השחקנים (עם תמיכה בפילטרים הפעילים)
- ✅ באדג'ים אדומים אוטומטיים לחוזה/ייצוג שמסתיימים בקרוב
- ✅ עברית מלאה + RTL בכל המערכת

## מה עוד לא בנוי (Phase 2/3 לפי המפרט — לא חובה בשלב הראשון)

- יבוא מאקסל/CSV
- חיפוש גלובלי חוצה-ישויות
- הרשאות משתמשים, גיבוי אוטומטי, העלאה לענן
- אינטגרציה חיה ל-SofaScore/Transfermarkt

## גיבוי

כל המידע נמצא בקובץ יחיד — `dev.db` בשורש הפרויקט. לגיבוי ידני, פשוט העתק
את הקובץ הזה למקום בטוח (למשל Google Drive) מדי פעם:

```bash
cp dev.db "backups/dev-$(date +%Y%m%d).db"
```

## הערת אבטחה

המערכת מכילה מידע רגיש על שחקנים, קטינים, חוזים ומשפחות. היא מיועדת לריצה
מקומית בלבד על המחשב שלך. אין להעלות אותה לענן או לחשוף אותה לאינטרנט לפני
שמוסיפים מערכת הרשאות, סיסמאות, וגיבוי מוצפן.
